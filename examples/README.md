# Examples

示例是书稿的可验证支撑，而不是与正文脱节的代码片段。每个示例目录应包含自己的 README，至少说明：目的、章节关联、环境、安装、运行、验证、预期与限制。

| 目录 | 计划用途 |
| --- | --- |
| `python/` | Python 版 Harness、检索、状态和评估示例。 |
| `typescript/` | TypeScript/Node.js 版工具协议和工作流示例。 |
| `flutter/` | Flutter 功能交付案例。 |
| `playwright/` | 浏览器端到端测试案例。 |
| `pytest/` | API、夹具和测试工作流案例。 |
| `agent/` | 最小可运行 Harness 与 Agent 循环。 |
| `evaluation/` | 评估、基准、成本和回归验证案例。 |

`agent/` 已包含第 1 至 47 章的 47 组可运行 Node.js 教学示例；其余子目录仅以 `.gitkeep` 保留，表示计划的示例位置，未放入不可运行的占位代码。
