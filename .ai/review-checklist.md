# Review Checklist

## 内容与读者

- [ ] 章节有单一、可观察的学习目标和清楚的前置知识。
- [ ] 场景、概念、案例、图示和总结回答同一个工程问题。
- [ ] 给出了失败模式、不适用条件和安全边界。
- [ ] 没有重复相邻章节已经完成的论证。

## 原创性、引用与事实

- [ ] 没有逐句翻译、拼接改写或大段复刻来源材料。
- [ ] 来源观点、本书工程扩展和待核验项已明确区分。
- [ ] 可归因事实都有可追溯来源并登记到 `.ai/references.md`。
- [ ] 动态产品信息使用写作当日的官方资料复核。

## 工程质量

- [ ] 示例说明环境、命令、预期和验证；已运行内容有真实结果。
- [ ] Mermaid 图有源文件、标题、读图说明和一致术语。
- [ ] 代码、图示、正文和目录中的命名一致。
- [ ] 相对链接、交叉引用和文件名可通过校验。

## 语言与交付

- [ ] 遵循 `STYLE_GUIDE.md`，没有空泛 AI 腔或无证据总结。
- [ ] 已运行 `npm run validate`，或记录未运行的命令和原因。
- [ ] 已更新 `CURRENT_STATE.md`、`NEXT_TASK.md`、`.ai/progress.md` 和必要交接。
