# Glossary

| 中文 | 英文 | 本书约定 |
| --- | --- | --- |
| Harness | Harness | 围绕基础模型组织上下文、工具、状态、流程、权限和评估的运行系统。 |
| Agent | Agent | 能在 Harness 中观察、推理、调用工具并产生行动的执行主体；不等同于单个模型。 |
| 上下文工程 | Context Engineering | 选择、压缩、组织和更新模型可见信息的工程实践。 |
| 工作记忆 | Working Memory | 当前任务期间的短期状态和中间结果。 |
| 长期记忆 | Long-term Memory | 可跨任务保存、检索和维护的知识、决策或经验。 |
| 技能 | Skill | 封装了输入、步骤、工具边界和验收条件的可复用能力。 |
| 技能契约 | Skill Contract | 本书用于描述 Skill 的触发、输入、前置条件、工具与副作用边界、输出、证据、维护与版本的工程模型；不是通用产品 schema 或授权机制。 |
| 项目记忆层 | Project Memory Layer | 为人类和 Agent 提供可定位、可追溯、可审查 Markdown 项目材料的本书工程模型；共同可读不等于共同权限、自动加载或自动写入。 |
| 记忆节点 | Memory Node | 用稳定标识、用途、状态、所有者、复核日期和指针描述一条项目记忆的本书记录；节点存在不证明内容正确、新鲜或已落实。 |
| 链接契约 | Link Contract | 为来源支持、审查覆盖、替代、阻塞和下一步等关系声明方向、含义与目标的本书工程模型；链接可点击不证明内容仍存在、正确或可访问。 |
| 生命周期记录 | Lifecycle Record | 为项目材料记录收集、核验中、稳定、已替代、归档或待删除状态及后继动作的本书工件；不自动触发迁移、删除、通知或审批。 |
| 记忆健康检查 | Memory Health Check | 以节点、关系、状态、来源、责任和新鲜度将教学记忆图保守路由为可继续、补证或人工复核的本书判定；不扫描真实文件、修改内容、判定事实或执行同步。 |
| 同步边界 | Synchronization Boundary | 在跨设备或协作前记录同步渠道、范围、负责人、冲突出口和备份责任的本书工程边界；不是 Obsidian Sync、Git 或云盘配置，也不授予访问或写入权限。 |
| 技能注册记录 | Skill Registry Record | 记录候选 Skill 的用途、触发条件、所有者、版本、依赖、评估状态和生命周期的本书治理工件；不安装、授权或执行 Skill。 |
| 准入审查 | Admission Review | 在发布前分开检查 Skill 结构、依赖、风险、评估与责任的本书治理过程；通过不等于获得运行时权限或业务验收。 |
| 质量等级 | Quality Tier | 显式区分实验、受限可用和受维护条目的本书分类规则；等级不是安全认证、SLA 或效果保证。 |
| 兼容性声明 | Compatibility Declaration | 说明一个 Skill 改动影响触发条件、输入、输出、依赖、工具边界或迁移路径的本书记录；未验证的声明不替代回归评估。 |
| 弃用记录 | Deprecation Record | 为停止推荐或移除的 Skill 保留原因、替代项、迁移期限和维护终点的本书记录；不自动迁移调用方或删除旧副作用。 |
| 工作流 | Workflow | 将任务拆成有顺序、有状态和可恢复步骤的执行协议。 |
| 工作流契约 | Workflow Contract | 本书用于说明工作流目标、范围、版本、合法状态、迁移证据、停止与升级条件的可审查工程模型；不是产品 schema、运行时或授权机制。 |
| 状态记录 | State Record | 描述一次具体执行当前可检查状态、关联证据、未知项和下一步候选的工程记录；不等同于长期记忆，也不自动证明外部效果。 |
| 检查点 | Checkpoint | 可用于恢复判断的已保存状态记录或快照；是否新鲜、完整、已提交或正确仍须以具体证据确认。 |
| 重入 | Re-entry | 再次处理某个状态或动作的情形；不等同于失败修复，也不自动允许安全重复。 |
| 幂等性 | Idempotency | 对同一已识别效果请求的重复处理不产生额外不可解释效果的工程目标；不等同于跨系统的 exactly-once 保证。 |
| 评估 | Evaluation | 用可观察标准判断结果或过程是否满足预期的机制。 |
| 反思 | Reflection | 从轨迹、失败或评估中提炼后续可执行改进的过程。 |
| 工具协议 | Tool Protocol | Agent 与外部工具交换参数、结果、错误及相关元数据的接口约定；具体字段和权限机制必须由具体协议或运行环境定义。 |
| 工具调用 | Tool Invocation | 一次被请求、路由并返回结果或错误的工具交互；调用已被提出或已发送，不等于外部效果已发生。 |
| 工具契约 | Tool Contract | 本书的审查模型：把 Tool Descriptor、Invocation Request、Invocation Record 与 Result Envelope 的边界写清楚；不是厂商 API、授权策略或审计后端。 |
| 工具描述 | Tool Descriptor | 描述工具的用途、非用途、输入/输出形状、限制和效果类别的工件；不授予访问或执行权限。 |
| 调用请求 | Invocation Request | 本书模型中带有关联标识、工具版本、已解析参数、环境与批准引用的可判定请求；不表示已发送或已产生外部效果。 |
| 调用记录 | Invocation Record | 用于关联请求、路由、时间、适配器和原始观察的追溯工件；不等同于完整状态机或审计系统。 |
| 结果信封 | Result Envelope | 本书模型中对关联标识、结果分类、规范化结果/错误、效果状态和未验证范围的表达；不等同于业务验收。 |
| 调用关联标识 | Call Correlation ID | 把一次工具请求与其结果、错误或观察记录关联的标识；本书术语，不假定任何产品字段名称。 |
| 效果不确定性 | Effect Uncertainty | 对具有外部副作用的操作，现有证据无法判定效果是否发生的状态；不等同于失败或可安全重试。 |
| 人类在环 | Human-in-the-loop | 在关键决策、审批、纠错或责任归属处由人类参与的系统设计。 |
| 环境契约 | Environment Contract | 本书用于在动作进入环境前审查允许效果、目标范围、文件、网络、凭证、批准、观察与停止条件的工件；不授予真实权限，也不等同于平台配置。 |
| 沙箱 | Sandbox | 限制进程能够触及的路径、网络或系统能力的技术执行边界；它不替代源系统授权、人工批准或结果验收。 |
| 凭证 | Credential | 供源系统识别请求主体的身份材料；凭证存在不等于任务范围合理、已获批准或动作已验收。 |
| 最小权限 | Least Privilege | 只授予完成明确任务所需的最小文件、网络、凭证、目标和效果范围的设计原则。 |
| 环境准入记录 | Environment Admission Record | 记录候选动作、环境 profile、目标范围、边界匹配、批准引用和后续观察要求的本书工程工件；不是部署或授权成功的证据。 |
| 知识库配置 | Knowledge Base Profile | 本书用于说明可索引资料、来源边界、更新策略和模型装配禁区的工程模型；不等同于某一向量数据库的实现。 |
| 证据单元 | Evidence Unit | 能回到来源位置、范围、时间和限制的最小可审查材料单元；相似度高不等于它足以支持主张。 |
| 检索策略 | Retrieval Policy | 用于限定查询范围、来源优先级、新鲜度、过滤条件和停止条件的本书工程规则；不保证检索结果正确。 |
| 证据卡 | Evidence Card | 将候选材料与来源位置、范围、新鲜度、限制和可支持主张关联的本书记录；不取代事实核验。 |
| 检索记录 | Retrieval Record | 记录查询、候选、筛选理由、未覆盖范围和输出装配决定的追溯工件；不证明真实资料库已被访问。 |
| 行动卡 | Action Card | 为候选动作记录意图、范围、效果、证据、未知项、成功标准和刷新条件的本书审查工件；不授予执行权限。 |
| 审批矩阵 | Approval Matrix | 将风险、可逆性、证据和策略条件映射到自动候选、人工审批、补证、阻塞或升级的本书路由模型；不代表身份或法律授权。 |
| 审批记录 | Approval Record | 关联具体候选、范围、证据与决定的可审查记录；不是数字签名、不可抵赖审计或环境准入证明。 |
| 刷新条件 | Refresh Condition | 指出何种范围、证据、环境、影响类型或时间变化会使旧决定不可复用的规则；当前第 14 章示例只实现范围和证据状态。 |
| 观察记录 | Observation Record | 把一次观察的关联标识、目标、来源、时刻、状态、新鲜度和限制绑定到同一对象的本书工程记录；不等同于真实日志、追踪协议或验收。 |
| 状态快照 | State Snapshot | 对受控目标某次读取结果的结构化表示；必须结合关联、来源、新鲜度和任务范围解释，不能单独证明因果、授权或完成。 |
| 关联标识 | Correlation ID | 将一次行动、观察和后续解释限定在同一对象上的标识；不是用户身份、权限声明或任何特定协议字段。 |
| 新鲜度 | Freshness | 证据在当前范围和决定中是否仍可使用的受限判断；不等同于统一 TTL、真实时钟正确性或永久有效。 |
| 推进性 | Advancement | 同一关联对象在行动前后是否获得不同且可解释观察的判断；不等同于外部副作用已经发生。 |
| 反思记录 | Reflection Record | 将失败轨迹、症状、可证伪假设、反事实、候选改变和验证状态关联的本书工程工件；不是已确认根因或自动写入的经验。 |
| 经验准入 | Lesson Admission | 对验证后的候选经验再次审查范围、冲突、可撤销性与责任的过程；不自动修改共享记忆、规则或策略。 |
| 可证伪检查 | Falsifiable Check | 能用明确观察支持或推翻某项假设的检查；检查存在不保证假设正确或覆盖全部替代原因。 |
| 反事实 | Counterfactual | 描述假设不成立时应转向何处补证或调查的分支；不是对真实因果关系的证明。 |
| 缺陷调查 | Bug Investigation | 关联任务范围、症状、预期、实际、证据缺口与停止条件的本书工程记录；不是已确认根因、事故报告或自动修复任务。 |
| 复现契约 | Reproduction Contract | 为一次受控复现声明输入、前置状态、失败判定、允许动作与不可信变量的本书模型；不是生产环境、真实账户或完整系统副本。 |
| 假设记录 | Hypothesis Record | 关联候选原因、可证伪预测、检查、观察与支持／推翻／未决状态的本书工程工件；被支持不等同因果已证明。 |
| 候选修复 | Fix Candidate | 将一个已获有限支持的假设、最小候选变化、预期影响与不得触及范围关联的本书工程记录；不是已写入、已合并或已发布的修复。 |
| 回归门 | Regression Gate | 同时审查原失败路径、修复后预期行为、关联范围与未覆盖项的本书判定器；不执行测试、Git、CI、浏览器或发布。 |
| 升级记录 | Escalation Record | 在证据不足、风险过高、复现不稳定或需要人工决定时保留停止理由与后续责任的本书工程记录；不替代事故响应、审批流程或责任分配。 |
| 企业控制平面 | Enterprise Control Plane | 为一次候选工作集中记录主体、租户、目标、能力、策略、预算、到期和升级条件的本书治理边界；不是企业身份、策略或审计系统。 |
| 执行平面 | Execution Plane | 接收受限决定并产生可关联观察的本书执行责任层；接收请求不等于获得权限、完成外部动作或产生业务效果。 |
| 策略决定记录 | Policy Decision Record | 把允许、拒绝或待批准的理由、限制、范围、关联与刷新条件保存为可审查工件；不是合规结论、不可抵赖日志或真实策略求值结果。 |
| 租户与数据边界 | Tenant and Data Boundary | 为教学工作声明主体、数据类别、允许目标、共享例外和预算约束的本书边界；不是实际隔离、身份认证或数据保留保证。 |
| 关联观察记录 | Correlated Observation Record | 把控制决定、受限执行请求与后续观察用关联标识连接的本书记录；关联不证明完整追踪、审计、因果或外部效果。 |
| 人工升级门 | Human Escalation Gate | 当风险、范围、预算、数据类别或证据不足超出声明条件时，把候选工作停止并路由给具名人工责任者的本书门；不自动授予批准或执行权限。 |
| 评估规格 | Evaluation Spec | 明确任务范围、成功标准、证据要求、评分规则、失败出口与不覆盖范围的本书验收契约；不是某一平台的配置格式。 |
| 评分器 | Grader | 将一部分证据转换为通过、失败或不确定结论的受限逻辑；评分器输出不自动证明完整任务结果。 |
| 证据矩阵 | Evidence Matrix | 把每项标准与其记录、范围、新鲜度、评分规则和限制逐一关联的本书审查结构；不是自动生成的事实库。 |
| 质量门 | Quality Gate | 根据明确规格和证据将教学任务路由为接受、拒绝、补证、复核或补规格的判定器；不执行外部动作或替代人类责任。 |
| 恢复契约 | Recovery Contract | 本书用于把失败分类、效果状态、可重复性、重试上限、检查点、补偿路径与升级条件写成可审查输入的工程模型；不执行重试、恢复或外部动作。 |
| 重试预算 | Retry Budget | 为一个受控范围限制可尝试次数或允许重试消耗的规则；不等同于某个产品的固定次数、延迟、容量或服务级别目标。 |
| 补偿 | Compensation | 对已知且可识别效果提出的业务特定纠正候选；补偿可失败、可需要检查点和人工介入，不等同于原子回滚。 |
| 恢复 Runbook | Recovery Runbook | 记录何时补证、重试、补偿、停止或升级的可审查操作指南；不是自动化执行器或真实恢复证明。 |
| 压缩记录 | Compaction Record | 将摘要、稳定事实锚点、证据指针、保留/丢弃理由、恢复入口和损失检测关联的本书工件；不等同于模型自动摘要、持久记忆或真实会话恢复。 |
| 稳定事实锚点 | Stable Fact Anchor | 在压缩后仍必须保留并能指向可复核证据的位置的任务事实；锚点存在不保证其当前正确或仍新鲜。 |
| 证据指针 | Evidence Pointer | 指向恢复时应重新读取的来源、记录或工件的定位信息；不表示目标可访问、内容正确或权限已获授。 |
| 再水化 | Rehydration | 用摘要之外的受控来源重新装配继续任务所需信息的过程；不自动恢复全部上下文或证明历史结论。 |
| 损失检测 | Loss Detection | 对压缩后缺失的锚点、指针、未决项或不确定性做显式检查的机制；检测通过不保证没有其他信息损失。 |
| 候选改进协议 | Candidate Change Protocol | 把改进目标、范围、基线、拟议变更、独立验证、批准、监控、回滚与停止条件写成的本书工件；不等同于发布、部署或自动自改进。 |
| 变更门 | Change Gate | 仅在独立验证、范围匹配批准、回滚准备和具名监控同时满足时把教学候选路由为受控发布准备的判定器；不执行发布、监控或回滚。 |
| 共享仓库契约 | Shared Repository Contract | 把稳定规则、当前任务状态、验证契约与交接包作为跨工具可审查项目工件的本书模型；不定义任何产品的文件发现、权限或强制执行。 |
| 产品适配声明 | Product Adapter Declaration | 记录产品标识、当前官方来源、复核日期、指令入口、权限边界与未验证范围的本书工件；不证明产品已配置、已加载或已获授权。 |
| 规则记录 | Rule Record | 以标识、层级、范围、指令、来源、状态、修订和冲突键描述单条规则的本书模型；不是 Codex、Claude Code 或其他产品的配置格式。 |
| 规则包 | Rule Packet | 在行动前组织适用规则、状态新鲜度和任务局部材料，并将缺层、冲突或范围泄漏路由为保守出口的本书教学输入；不表示真实文件已被加载。 |
| 钩子 | Hook | 在明确工具或运行生命周期事件附近执行受控处理的机制；事件、顺序、信任、权限和脚本安全必须由具体产品或运行环境核验。 |
| 自动化检查 | Automation | 由外部事件或计划启动、具有输入范围、命令/报告、失败策略与所有者的可见检查；不自动授予写入、发布或无人值守修复权限。 |
| 插件 | Plugin | 用于安装或分发能力、配置或资产的打包单元；不创造独立的执行、授权或验收语义。 |
| Server Profile | Server Profile | 记录候选外部 Server 的来源、所有者、传输边界、允许目标、刷新条件和未知项的本书工程工件；不是连接配置、凭证或信任授予。 |
| 工具准入记录 | Tool Admission Record | 将一次特定工具请求的任务范围、效果类别、环境、scope、批准和观察计划关联的本书工件；不代表调用已发送或权限已生效。 |
| 调用信封 | Invocation Envelope | 将准备调用的关联标识、工具、输入摘要、效果类别、批准引用和观察计划绑定的本书记录；不表示真实请求已送出。 |

| 人类责任图 | Human Responsibility Map | 记录风险所有者、受影响者、独立审查者、批准者、停止者、申诉入口和事件响应者的本书责任工件；不创建组织授权或保证责任充分。 |
| Agent 资产登记 | Agent Asset Register | 记录 Prompt、Skill、Tool Schema、模型、依赖、评估集和策略的来源、版本、审查、分发、撤销与未覆盖风险的本书候选清单；不等同供应链认证或安全证明。 |
| 回归矩阵 | Regression Matrix | 比较 Harness、模型、Tool、数据和评分器身份及桥接证据是否足以复用评估结论的本书工件；不替代回归测试矩阵中的试次结果或统计有效性判断。 |
| 事实核验 | Fact Check | 对可归因陈述、数据、产品行为和引用进行来源级确认。 |

术语调整应先记录理由，再同步检查书稿、图示、模板和示例。
