# 项目上下文

`.context/` 让没有聊天记录的 AI 或贡献者快速回答四个问题：项目是什么、为什么这样设计、当前完成了什么、下一步做什么。

| 文件 | 作用 |
| --- | --- |
| `PROJECT_CONTEXT.md` | 项目定位、边界、读者和事实来源 |
| `ARCHITECTURE.md` | 内容、上下文、模板和自动化的分层关系 |
| `CURRENT_STATE.md` | 已完成、正在进行、阻塞与最近验证 |
| `NEXT_TASK.md` | 按优先级排序的可验收下一任务 |
| `DECISIONS.md` | 关键设计决策和后果 |
| `ROADMAP.md` | 阶段路线和发布目标 |
| `HANDOFF.md` | AI 或人类之间的接力记录 |
| `FAQ.md` | 常见工作方式和边界说明 |

状态文件必须随任务完成更新；不要以聊天记录替代这些文件。
