# 第 26 章 Language Editing：多 Agent 协作与任务隔离

## 编辑结论

- 首次出现统一为任务契约（Task Contract）、所有权声明（Ownership Claim）、交付包（Delivery Package）和集成门（Integration Gate）；后文沿用相同名称。
- 将“并行”限定为候选与工件边界，不将“图中有两个 Agent”写成已发生的多 Agent 运行。
- 以“谁负责什么、缺什么证据、何时停止”替代“提高协作效率”“自动解决冲突”等空泛措辞。
- 将产品事实限定为 Python SDK 文档和写作日访问，不把 manager、handoff 或 input filter 写成跨产品协议。
- 表格中的“不代表什么”列保留，以避免任务所有权、局部绿色测试或集成者职责被误读为权限、执行或验证成功。

## 未改变的内容

本次编辑没有扩大来源范围、改变示例 API、修改 Mermaid 语义、增加真实运行结论或更改共享状态工件。
