# 47 章工件矩阵独立审计

## 审计范围与方法

本轮只做只读盘点与路径解析，唯一写入是本审计记录。未修改章节正文、阶段记录、共享状态、目录、全局引用、示例、测试、图示或配置。

1. 先用 `rg --files` 盘点 `docs/`、`.memory/reviews/`、`examples/`、`diagrams/mermaid/` 与 `diagrams/exported/`。
2. 将唯一正文限定为文件名严格匹配 `NN-<slug>.md` 且 `<slug>` 不含阶段后缀；Research、Outline、References、Fact Check 与 Example Plan 必须与正文 stem 精确对应。
3. Final Review 记录按 `.memory/reviews/YYYY-MM-DD-chapter-NN-final-review.md` 计数，日期不作为章节归属的一部分。
4. 解析 47 份正文 YAML front matter；`status` 必须属于模板允许的 `research / outline / draft / review / complete`，`diagrams` 与 `examples` 按正文目录解析相对路径并检查存在性。
5. 从正文 `references` 提取 REF ID，并与 `.ai/references.md` 表格中的全局 REF ID 集合比较。
6. 统计 `examples/**.test.mjs`；再以每章正文、Example Plan 与 Final Review 的合并文本反查测试文件名，检查一章一项且 47 项互不重复。这里只验证文件与引用关系，不执行测试。
7. 按 `chapter-NN-<topic>` stem 比较 Mermaid、SVG 与 PNG；每章必须各一份，三种扩展名的 stem 必须相同。
