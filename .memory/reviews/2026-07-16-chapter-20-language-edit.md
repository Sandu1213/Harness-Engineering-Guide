# 第 20 章 Language Editing

## 范围与结论

已按 `STYLE_GUIDE.md` 检查第 20 章正文及辅助工件：首次出现使用“候选改进（Improvement Candidate）”“候选改进协议（Candidate Change Protocol）”“变更门（Change Gate）”；中文与英文术语之间保留空格；段落以工程问题、条件、边界和可观察结果组织。

本次编辑收束了三个容易误读的表达：

- 统一使用“受控发布准备”，不把它写成“已发布”。
- 将“独立验证通过”与“范围批准”拆成不同句子，避免读者把测试结论理解为权限结论。
- 将长期运行写成带预算、所有者、漂移、停止和升级条件的治理问题，而非“持续自动学习”的宣传语。
