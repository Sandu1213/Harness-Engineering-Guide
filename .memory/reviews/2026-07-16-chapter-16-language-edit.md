# 第 16 章 Language Editing

日期：2026-07-16

## 编辑范围

检查正文、Research Brief、Outline、Fact Check、示例计划和审查记录的术语首现、主语、事实层级、段落节奏与链接表述。

## 编辑结论

- 首次出现统一使用“反思（Reflection）”“反思记录（Reflection Record）”“经验准入（Lesson Admission）”“可证伪检查”等术语；避免把候选、经验和已采纳规则混用。
- 来源段落均以“论文提出”“页面描述”“文章的限定建议”等主语表述；本书字段、状态、案例和判断规则明确标为工程模型或教学输入。
- 将“根因”改为“根因假设”或“尚不能归因”的位置保持一致，避免夸大模型或示例的证明力。
- 场景、代码、图示和测试说明均强调：示例不访问真实链接或网络，演示输出不是实际经验写入。

本次编辑不改变来源范围、示例接口、测试断言或 Mermaid 语义。
