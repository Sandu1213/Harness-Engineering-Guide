# Appendices

附录把正文中的方法收束为可直接复制、检查和交接的资产。它们不替代对应章节、项目规则或权威登记：模板负责复用，章节解释设计理由，`.ai/glossary.md` 与 `.ai/references.md` 继续分别承担术语和来源的单一事实源。

| 附录 | 内容 |
| --- | --- |
| [A. Prompt Library](a-prompt-library.md) | 按场景检索、带输入、边界、输出和验证方式的 Prompt Card。 |
| [B. Skill Library](b-skill-library.md) | Skill Contract、注册表、测试矩阵与生命周期。 |
| [C. Workflow Library](c-workflow-library.md) | 章节生产、软件变更、角色队列与失败恢复工作流。 |
| [D. Memory Templates](d-memory-templates.md) | 项目事实、决策、经验、研究摘要与交接记录模板。 |
| [E. Evaluation Checklists](e-evaluation-checklists.md) | 结果、过程、示例、图示、章节与发布质量门。 |
| [F. Reflection Checklists](f-reflection-checklists.md) | 复盘、根因假设、经验准入与改进试点评估。 |
| [G. Mermaid Guide](g-mermaid-guide.md) | 图示契约、语法、命名、渲染、视觉与语义审查。 |
| [H. Research and Citation Guide](h-research-and-citation-guide.md) | 来源分级、Evidence Card、引用、版权与 Fact Check。 |
| [I. Codex Handoff Template](i-codex-handoff-template.md) | Codex 接力的读取顺序、状态、证据、风险与下一步模板。 |
| [J. Claude Code Handoff Template](j-claude-code-handoff-template.md) | Claude Code 接力的项目记忆、会话和工具差异模板。 |
| [K. Glossary](k-glossary.md) | 面向读者的主题术语与易混淆概念导航。 |
| [L. References](l-references.md) | 面向读者的来源追溯流程与章节引用索引。 |

所有模板中的路径、日期、ID、版本、权限和责任者都是待填写字段。复制模板不会自动读取上下文、授予能力、执行命令或证明外部结果。
