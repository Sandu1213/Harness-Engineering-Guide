- 本章没有创建或运行任何 MCP Server/Client、stdio/HTTP 传输、OAuth 流、浏览器、文件、网络、凭证或外部工具。
- 未验证信息必须保留为 `TODO(verify):`，不能因 schema、文档或示例存在而包装为已完成集成。
- REF-149、REF-150、REF-151 已于 2026-07-26 重读；作者选择、特定环境测量与本书 Tool Admission 模型保持分层。
