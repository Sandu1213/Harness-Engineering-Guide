# 第 21 章详细提纲：Claude Code 与 Codex 的项目 Harness

## 章节目标与依赖

- **目标：** 读者能区分共享仓库 Harness 与产品适配层，设计可由 Codex、Claude Code 或其他 Agent 接手的规则、状态、验证和交接工件，并为每个动态产品事实保留官方复核边界。
- **前置：** 第 03 章的仓库上下文；第 05 章的指令分层；第 08 章的可复用能力；第 10 至 12 章的工作流、工具与环境边界；第 20 章的范围与停止边界。
- **后续：** 第 22 章将拆解仓库规则；第 23 章比较 Skill、Hook 和自动化；第 45 章把本章的交接契约扩展为长期跨工具协作。
