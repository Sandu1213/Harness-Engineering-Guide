## 本书工程模型核验

下列术语均非来源的原话或产品字段，正文已标为“本书模型”：

| 术语或状态 | 本书用途 | 不代表 |
| --- | --- | --- |
| Compaction Record | 把摘要、锚点、指针、保留/丢弃、再水化与损失检测编排为可审查记录。 | 通用标准、数据库 schema 或厂商 API。 |
| 稳定事实锚点 | 防止任务目标、范围、契约版本、关键决定和未知项在摘要中消失。 | 已被真实环境重新验证的事实。 |
| 证据指针 | 在被授权时重新定位可审查材料。 | 文件、网络、账户或数据访问授权。 |
| `ready_to_resume` | 注入教学对象通过本章记录检查。 | 任务完成、实际恢复、权限允许或外部效果确认。 |
| `needs_rehydration` | 先回到对应材料或当前状态再判断。 | 自动读取、自动恢复或安全重试。 |
