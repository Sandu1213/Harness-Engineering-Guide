# Part 7：Book Factory 与未来

本部分把本书作为案例，说明 AI Technical Book Factory、跨工具交接、长期上下文与内容再利用，并以开放问题结束全书。

## 章节

- [43. 用 Harness 写一本技术书](43-writing-a-technical-book-with-harness.md)：把章节契约、证据包、阶段门和集中验证组合成 Book Harness。
- [44. AI Technical Book Factory：Research、Writing 与 Review Agent](44-ai-technical-book-factory-research-writing-and-review-agent.md)：定义角色契约、版本化队列、双硬门、冲突路由和有界返工。
- [45. Codex、Claude Code 接力与长期项目上下文](45-codex-claude-code-handoff-and-long-term-context.md)：用共享项目核心、工具适配档案和恢复准入支持跨工具接力。
- [46. 从书籍扩展到课程、博客和知识库](46-books-to-courses-blogs-and-knowledge-bases.md)：从规范事实源派生不同媒介内容，并用一致性门限制漂移。
- [47. Agent Engineering 的未来与结语](47-agent-engineering-future-and-conclusion.md)：回收稳定工程责任、开放问题、标准化阶梯和读者实践路线。
