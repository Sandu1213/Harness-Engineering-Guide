# 第 32 章 Research Brief：自动分析失败并修复 Bug

## 要解决的工程问题

Agent 看到失败信息后若立刻改代码，可能把偶发时序、错误前提、测试缺陷和真实产品缺陷混为同一原因。本章研究如何先把症状、预期与实际结果收集成可检查记录，再以最小复现和可证伪检查缩小原因集合；只有补丁能同时解释复现与回归检查时，才允许进入有限的修复结论。

## 读者问题与范围

| 读者问题 | 本章研究的回答 | 本章不回答 |
| --- | --- | --- |
| 如何避免“看到报错就猜修复”？ | 先建立症状、预期、实际结果和复现条件；每个候选原因都要有能够支持或推翻它的预测与检查。 | 自动识别所有根因，或替代领域知识与人工判断。 |
| 最小复现为什么有价值？ | 研究将仍能触发同一失败的输入或条件逐步缩小；若存在通过与失败样本，可研究它们的差异。 | 任意失败都能自动最小化，或最小样例天然等于生产根因。 |
| 修复后如何不把偶然通过当作解决？ | 把原失败的受控复现、修复后的预期行为和未覆盖范围放入回归门。 | 任何一条绿色测试都证明发布、性能、并发或外部效果正确。 |
| 多次调查没有进展时怎么办？ | 为调查规定证据缺口、尝试上限和升级出口；负面结果保留在假设记录中。 | 本书给出跨项目通用的失败次数、超时或自动升级阈值。 |

## 本书研究框架

下列名称是本书为教学案例提出的工程工件，不是 Delta Debugging、Google SRE、Git 或 Playwright 的固定数据结构或自动化能力。

| 工件或边界 | 要解决的问题 | 关键限制 |
| --- | --- | --- |
| Bug Investigation | 关联任务范围、症状、预期、实际、环境声明、证据缺口与停止条件。 | 调查记录不是已经确认的根因。 |
| Reproduction Contract | 为一次受控复现声明输入、前置状态、失败判定、允许动作与不可信变量。 | 复现契约不是生产环境、真实账户或完整系统副本。 |
| Hypothesis Record | 记录候选原因、可证伪预测、最低风险检查、观察和被支持／推翻／未决状态。 | “被支持”不等同因果已经证明；“未决”不等同失败已消失。 |
| Fix Candidate | 把针对一个已关联假设的最小候选变化与预期影响分开记录。 | 候选补丁不自动获得写入、合并或发布授权。 |
| Regression Gate | 同时检查原失败路径、修复后行为、相关范围与未覆盖项，再决定是否接受有限结论。 | 回归门不执行测试、浏览器、Git、CI 或生产变更。 |
| Escalation Record | 在证据不足、风险过高、复现不稳定或尝试达到项目约束时说明为何停止和由谁处理。 | 不替代事故响应、审批流程或责任分配。 |

## 教学案例、图示与示例计划

教学案例延续第 31 章的虚构网页登录流程：一项 UI 检查偶发地在提交后立即读取结果，部分尝试没有获得预期观察。案例不宣称真实 Playwright、浏览器、账户、接口、网络或报告存在。调查先把“动作后观察缺失”记为症状，不把它直接写成“等待条件错误”；随后缩小复现条件，分别比较页面动作前条件、动作、观察断言与替代解释。只有某个可证伪检查排除竞争解释后，才允许把“等待条件与可观察状态不匹配”写为候选原因，并为它设计回归门。

后续图示应展示：Symptom Record 先进入安全／严重性分流，再进入 Reproduction Contract、最小化、Hypothesis Record 与 Falsifiable Check；通过检查的 Fix Candidate 仍必须经过 Regression Gate，失败、未决或风险过高的路径进入 Escalation Record。图中必须保留“症状不是根因”“补丁不是验证”“绿色检查不是发布”三处断点。

后续最小示例应只评估注入的 Bug Investigation，例如检查是否有可复现失败判定、每项假设是否含预测和检查、修复是否关联到一个被支持的假设、回归门是否同时覆盖原失败与预期行为。Example Implementation 阶段才决定是否建立纯内存实现和 Node 测试；本阶段不创建或运行 Bug 修复、pytest、Playwright、浏览器、API、Git bisect、CI、环境、账户、凭证或外部系统动作。

## 风险、非范围与后续核验

- 最小样例可能因时序、并发、配置、数据或外部依赖而失去原失败；“不能稳定复现”必须保留为调查状态，不能伪装成修复成功。
- 不把单次失败、日志关键词、测试超时、一次二分结果或单条绿色回归检查写成根因证明。
- 不记录或使用真实仓库提交、分支、命令输出、账户、令牌、浏览器 profile、接口响应、生产日志或外部截图。
